# Code Of Conduct

This project follows a practical standard for respectful, research-focused
collaboration.

## Expected Behavior

- Be direct, professional, and constructive.
- Focus technical discussion on evidence, reproducibility, and clear tradeoffs.
- Assume collaborators are working in good faith.
- Make uncertainty explicit when interpreting HPC behavior.
- Respect privacy and operational constraints around shared computing systems.

## Unacceptable Behavior

- Harassment, intimidation, discriminatory language, or personal attacks.
- Sharing private credentials, SSH keys, tokens, or user-specific access details.
- Publishing sensitive HPC account, path, allocation, or dataset information.
- Misrepresenting benchmark-like results as production performance guarantees.
- Pressuring contributors to run unsafe or inappropriate workloads on shared
  systems.

## Reporting

Report concerns through the maintainers or the repository issue tracker. If the
concern involves private access details, credentials, or sensitive system
information, do not post those details publicly.

Maintainers should respond by clarifying the concern, preserving privacy, and
taking proportionate action to keep the project useful and safe for
collaboration.
